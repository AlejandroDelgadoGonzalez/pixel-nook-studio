## Gates 1 and 2A only

The request to run this workflow authorizes preparing both gates as one review packet. Develop the causal script first, then measure its art. It does not approve either gate or authorize Gate 3.

Gate 1: English story text, 60–80 seconds planned automatic reading. Supply a chapter-map reference, eight-year-old clarity table (place/time, provenance/present/absent, motive, action, consequence, next connection) and numbered beats with exact time ranges and text. Every silent beat must contain visible physical action and last at most eight seconds; contiguous silent actions must also total at most eight seconds. No static opening/closing bridges, repeated premises, or narration mechanically describing visible action. Start from the real prior state without an unnecessary dissolve. Distinguish proposed timing from measured runtime timing.

Gate 2A: prefer exact certified assets and native decoded poses. Inspect the actual panorama and complete silhouettes before assigning contact points/routes. Record spawns, roots, supporting surfaces, anchors, ordered straight/non-zigzag paths, prop ownership, pickup root anchors and any actual occluders. New indispensable art requires the relevant image-generation workflow, direct canonical concept_art inputs, provenance, native contracts and qa/pixel_density.py check PASS. Never chain scene images as style masters. Do not modify an approved panorama merely to fit a proposal.

Measure 360x800, 390x844, 430x932, 1366x640, 1280x720 and 1080x1920 using qa/official-layouts.mjs. Include complete silhouettes and intermediate route/transformation samples, background coverage, shared X/Y dramatic focus, actual per-layout zoom/center, top clearance and fixed bottom #dialogue reserve. Read the actual reader CSS/font measurements; do not guess a 30% reserve. Test Auto/9:16/16:9 where relevant. Prefer smooth fixed-zoom pans (at least 1.2 seconds) during silent physical action if needed; never move the camera while #dialogue is visible. A visible card is complete, enabled and immediately clickable with a pointer. Hidden cards retain their layout reserve. Declare future implementation obligations separately from static checks; an HTML board is not a Phaser runtime, MP4 or physical-phone certificate.

Technical PASS does not mean Alejandro approved the narrative or visuals.
